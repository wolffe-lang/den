I expect one bounded pkt-line parser/encoder to serve protocol-v2 advertisement,
ls-refs and fetch, sideband framing, and receive-pack's update/report messages.
Unit rows will cover partial headers/bodies, special packets, binary payloads,
maximum packet length, invalid lengths and the distinction between flush,

Receivers must tolerate missing LF as gitprotocol-pack requires: the required
want-without-LF plant therefore fails a named outbound-byte assertion, not an
invented assertion that the Git server must reject an optional LF.

I expect file transport to use argument-vector child processes with mapped
pipes, and git transport to use TCP plus the documented service request.
Production transport must never invoke Git as a substitute for den's parsers,
pack encoder/decoder, object validation or reference updates. Independent clients
will exercise the exported modules. Fixture byte streams and command captures
will be retained, comparing deterministic bytes and otherwise canonical objects,
refs and git fsck. Thin REF deltas should reuse apply_delta and resolve an
external base from the local object store; never persist a thin pack as-is.

R-vc15-3 atomic-ref recommendation (2026-11-02 resume): use a single
packed-refs rename as the logical commit point, not sequential loose ref
renames described as atomic. Lock every target and packed-refs; validate all
expected IDs/types/policies before publication. Prepare a packed snapshot of
all old target values, publish that representation without changing any
logical ref, and remove same-value loose target shadows while locks remain
held. Then rename the prepared new packed-refs once. Failure before that
last rename leaves all logical values old, even if representation changed;
success changes all target values together. Do not claim crash recovery,
reflog transactions or generic worktree updates. Refuse unmeasured policy
rather than ignore it. Tests must cover loose and packed targets, stale old
IDs, foreign locks, multiple updates/deletes, Git visibility and fsck.
Alternative sequential loose publication is rejected: it cannot supply the
advertised all-or-none outcome on a late publication failure. Bare repositories
without reflog policy are the initial measured scope.
