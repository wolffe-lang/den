## Prediction

Recorded before implementation; predictions, not measurements:
- Git 2.56.0 writes no index extension immediately after the first add of two
  files; write-tree and commit each write TREE and no other extension.
- Adding a new root file retains TREE with root entry count -1, child count 0,
  and no root OID (the cache is invalidated, not globally discarded).
- The generated status matrix will measure 48 distinct complete stdout texts.
- --date=now is not deterministic under GIT_COMMITTER_DATE alone: author time
  still follows the wall clock. Recommend a named refusal unless measured otherwise.
- The final main differential case list will contain 300 cases (86 inherited
  plus 214 new); separate generated matrices will be counted independently.
- The stat-proof harness will validate 512 per-entry tool-side stat rows.
