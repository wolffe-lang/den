vc10 prediction, before implementation
The existing three resolution adapters disagree on tags, refs and ancestry. One pure bounded AST should expose atoms, ordered suffixes, literal raw paths, exclusions and range endpoints; repository lookup and set walking should be separate layers.
Git's documented ref search order picks a tag before a branch and emits a warning, rather than failing. Short object collisions require distinct diagnostics from missing names. Parent zero peels a tag to a commit; tilde walks only first parents, and caret selects ordered parents.
Range selection must exclude ancestry before max-count/skip, and three-dot excludes all shared ancestors rather than guessing a first merge base. Diff ranges are endpoint comparisons, not history walks; single-revision mutation consumers must not accidentally select sets.
HEAD reflog and the current branch reflog differ; previous checkout uses HEAD checkout messages, not arbitrary resets. Upstream needs configuration and will be refused by name when unsupported. Numeric reflogs are bounded inert data.
Literal tree traversal must preserve byte paths and never call index.write_tree. Parser checking should use a small module with actual checked exit evidence. Existing merge/replay/history boundaries remain named. Loose and packed fixtures should give identical grammar results and all inherited matrices remain mandatory.
